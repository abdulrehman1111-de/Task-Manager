# Task Manager

A full-stack task management application built with React and JavaScript. The application is designed to support project management, task assignments, subtasks, comments, and role-based access.

## Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- React Router
- Redux Toolkit
- Tailwind CSS
- Axios

### Development Tools
- Vite
- pnpm
- ESLint
- Git and GitHub

## Planned Features

### Authentication
- User login and logout
- Session management
- User profile management

### Admin
- Manage users
- Create, update, and delete projects
- Assign projects to users

### User
- View assigned projects
- View project details
- Manage tasks and subtasks
- Assign tasks to users
- Create and manage comments and replies

### Access Control
- Role-based permissions
- Admin and user-specific functionality

## Getting Started

### Prerequisites
- Node.js
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/abdulrehman1111-de/Task-Manager.git
cd Task-Manager
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```
